# مخطط الأثاث V13 — iPad / GitHub Pages

هذه النسخة جاهزة للنشر كموقع ثابت على GitHub Pages ويمكن إضافتها إلى شاشة iPad الرئيسية كتطبيق PWA.

## نشرها على GitHub Pages
1. أنشئ Repository جديدًا في GitHub، مثل `furniture-planner`.
2. ارفع **محتويات هذا المجلد نفسها** إلى جذر الـ Repository، بحيث يكون `index.html` في الجذر.
3. افتح: **Settings → Pages**.
4. تحت **Build and deployment** اختر **Deploy from a branch**.
5. اختر Branch: `main` والمجلد: `/ (root)` ثم **Save**.
6. بعد دقائق سيظهر رابط GitHub Pages. افتحه مرة واحدة على iPad أثناء وجود الإنترنت.

## إضافته إلى شاشة iPad الرئيسية
1. افتح رابط GitHub Pages في **Safari**.
2. اضغط زر **Share**.
3. اختر **Add to Home Screen**.
4. اضغط **Add**.

بعد أول فتح من الرابط، يقوم Service Worker بتخزين ملفات البرنامج الأساسية لتعمل النسخة لاحقًا دون إنترنت في معظم الحالات.

## استخدام اللمس على iPad
- اضغط قطعة أثاث ثم المس مكان وضعها على الخارطة.
- أو اسحب القطعة بالإصبع من زر **⠿** الصغير داخل بطاقة الأثاث إلى موقعها على الخارطة.
- عند التكبير، اسحب منطقة فارغة من الخارطة لتحريكها.
- في الوضع العمودي، زر **☰ المكتبة** يفتح ويغلق المكتبة الجانبية.
- استخدم زري **+ / −** أو منزلق التكبير.

## ملاحظات
- تشغيل `index.html` مباشرة من تطبيق Files ليس هو الوضع الموصى به على iPad؛ استخدم رابط GitHub Pages لكي تعمل PWA والتخزين دون إنترنت بشكل صحيح.
- بيانات المكتبة المخصصة تحفظ في متصفح Safari/التطبيق المثبت على نفس الجهاز.

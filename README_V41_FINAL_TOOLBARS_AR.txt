تأثيثي V41 — إعادة بناء الواجهة من النسخة المستقرة V35

تم تنفيذ التعديلات من نسخة نظيفة لتجنب تكرار أكواد V36–V40.

أهم التغييرات:
- زر «فتح مشروع» أصبح زرًا حقيقيًا مستقلاً يستدعي اختيار ملف JSON مباشرة.
- شريط علوي واحد للأيقونات الأساسية بدون شريط تمرير أفقي في عرض الكمبيوتر/الآيباد المعتاد.
- سطر ثانٍ منفصل أسفل الأيقونات يحتوي فقط على:
  1) التكبير/التصغير
  2) حجم القياسات
  3) حجم المسميات
- شريط أثاث عامودي ثابت في أقصى يسار مساحة العمل، وبعدد أدوات أكبر (18 أداة).
- أدوات الشريط اليساري: تحديد/تحريك، تكبير، تصغير، دوران 90، دوران 45، إعادة الدوران، تلوين، إظهار/إخفاء، أسماء الأثاث، قياسات الأثاث، Snap، أمام/خلف، تحديد الكل، قفل، نسخ، إلغاء التحديد، حذف.
- الأيقونات أكبر وأوضح على الكمبيوتر، وتصغر تلقائيًا على iPad والموبايل.
- الوظائف الأقل استخدامًا تختفي تلقائيًا على شاشة الهاتف الصغيرة للحفاظ على ترتيب الشريط.
- إزالة أزرار التحكم المكررة من الشريط السفلي مع إبقاء حقول الاسم/المقاسات/الدوران/اللون.
- تحديث Service Worker باسم كاش جديد لإجبار GitHub Pages على عرض النسخة الحديثة.

بعد الرفع إلى GitHub Pages:
- اضغط Ctrl + F5 مرة واحدة.
- إذا بقيت نسخة قديمة افتح الموقع في نافذة خاصة أو امسح بيانات الموقع.

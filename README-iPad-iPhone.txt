FurniPlan V195 — iPad & iPhone

This is the standalone web-app edition of FurniPlan.

To install it on an iPad or iPhone:
1. Open its HTTPS link in Safari.
2. Tap Share.
3. Tap Add to Home Screen.
4. Open FurniPlan from the new sofa icon.

The app opens in English by default and includes the unified full library,
the highlighted Library button in the top toolbar, and free plan panning.

The files in this folder must be hosted together on an HTTPS web server.

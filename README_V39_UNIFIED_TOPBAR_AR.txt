تأثيثي V39 — شريط علوي موحّد + شريط عمودي ثابت يسار

ما تم في هذه النسخة:
- جعل الواجهة تعتمد على شريط علوي واحد موحّد.
- نقل أدوات الخارطة والإظهار/الإخفاء والتكبير والرجوع إلى الشريط العلوي.
- جعل شريط أدوات القطعة المحددة ثابتًا في أقصى يسار البرنامج.
- تكبير الأيقونات قليلًا لتكون أوضح.
- جعل شريط اليسار بنفس مقاسات أيقونات الشريط العلوي تقريبًا.
- تقليل تكرار أشكال الأيقونات، خصوصًا أقفال الوظائف المختلفة.
- تحسين تحجيم العناصر للأيباد والموبايل حتى تبقى ثابتة ولا تخرب شكل البرنامج.
- تحديث Service Worker لمنع ظهور نسخة قديمة من الكاش.

بعد الرفع على GitHub Pages:
1) افتح الموقع.
2) اضغط Ctrl + F5.
3) إذا بقيت النسخة القديمة، افتح نافذة خاصة أو امسح بيانات الموقع.

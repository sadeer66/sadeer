تأثيثي V45.1 — إصلاح صور مكتبة الأثاث

هذه النسخة مُهيأة للرفع من متصفح GitHub بالطريقة العادية.
كل صور المكتبة موجودة في جذر المجلد، ولا توجد مجلدات فرعية مطلوبة.

طريقة الرفع:
1) فك الضغط.
2) افتح المجلد الناتج.
3) Ctrl+A لاختيار جميع الملفات.
4) اسحبها إلى صفحة Upload files في مستودع sadeer66/sadeer.
5) Commit changes.

الإصلاحات:
- إصلاح 21 مسار صورة كانت تشير إلى PNG بينما الملفات الفعلية WebP.
- وضع كل صور preview و top-view في الجذر حتى لا تضيع عند الرفع من File Picker.
- ربط المعاينة المنظورية والصورة العلوية لكل قطعة.
